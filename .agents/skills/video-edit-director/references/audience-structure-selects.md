# 观众承诺、结构与选片

## 观众承诺

观众承诺不是营销口号，而是这条片子能用真实素材兑现的观看价值。它应说明正确观众为什么继续看，以及结束时获得什么理解、感受或结果。

## 观众状态变化

结构应描述观众状态怎样变化：不知道到知道、怀疑到相信、混乱到理解、期待到兑现、距离到共情。段落存在的理由是推进这种变化，而不是满足固定模板。

## Stringout

先建立尽可能完整、可回链的素材工作视图，避免只根据最先发现的片段做决定。Stringout 用于保留素材关系，不等于最终时间线。

## Selects

Selects 是针对当前项目目的的候选集合。每个候选说明用途、完整性、表演、画面、声音、余量、重复和代价；“好镜头”不是脱离项目的永久属性。

## Paper Edit / Radio Edit

语言驱动项目可以先形成内容和声音骨架，但必须回到真实画面、动作、反应和空间检查，不能把逐字稿顺序直接当成最终剪辑。

## 结构反事实

对关键段落比较删除、提前、延后、合并、拆分和替换后，观众承诺是否更清楚。结构复杂度必须由真实推进需要证明。

## 开场与收束

开场应尽快建立观看方向和真实承诺，不强制套用冲突、问题或高速蒙太奇。收束应完成承诺、留下正确余味或明确下一动作，而不是仅因为时长结束。
